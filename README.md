# 🛡️ منصة ميثاق | نظام إدارة وتتبع عهد المركبات العسكرية
---

## 📌 عن المشروع (About)
**منصة ميثاق** هي نظام ويب برمجي مُصمّم خصيصاً لقسم الإمداد والتموين لرقمنة وتنظيم عمليات تسليم واستلام عهد المركبات، ومتابعة حالاتها والعهد المتأخرة بأسلوب تفاعلي وسهل الاستخدام.

---

## ✨ المميزات الرئيسية (Key Features)

* **📊 لوحة تحكم وإحصائيات مباشرة (Dashboard):**
  * عرض إجمالي المركبات المتاحة بالمؤسسة.
  * متابعة المركبات المُسلّمة للعهد.
  * حصر العهد النشطة والتنبيه بالعهد المتأخرة.
* **🚗 إدارة المركبات والموظفين:** سجل متكامل لبيانات السيارات والموظفين المستلمين.
* **🔑 تسليم واستلام العهد:** إجراءات موثوقة لعمليات تسليم العهدة وإرجاعها.
* **📈 التقارير والتنبيهات:** متابعة فورية لحالة الاتصال بقاعدة البيانات والتقارير الدورية.
* **🎨 تصميم متجاوب (RTL):** واجهة مستخدم حديثة تدعم اللغة العربية بالكامل مع استخدام هيدر وشعار رسمي.

---

## 🛠️ التقنيات المستخدمة (Tech Stack)

* **Backend:** PHP (PDO)
* **Database:** SQLite / SQL
* **Frontend:** HTML5, CSS3, Bootstrap 5, FontAwesome Icons
* **Version Control:** Git & GitHub
